# 《在海风消失之前》制作方案

## 目标与承接

- 独立网页视觉小说，沿用第一部的点击阅读、存读档、回顾、结局收集与标题界面。第一部文件不改动。
- 完整接入现有续作剧本。共通线只承接五人共有的事实；四条恋爱线分别承接原作 TRUE-A 至 TRUE-D，普通线与新 TRUE 线承接 TRUE-E。平行路线不混写。
- 原作天文台事故已有结论，不重新制造悬疑。毕业与远行是第二部核心冲突。
- 玩家看到的选项只写当下可执行的行动或真实话语。隐藏路线代号、角色全名、结局名称、好坏提示及箭头说明。主界面的未解锁 TRUE 入口也不剧透内容。

## 流程与验收

1. 将原剧本转成可追溯的结构化数据，保留原文与源行号；去掉玩家不该看到的编剧批注。
2. 共通线进入五个自然行动方向；四条恋爱线各有 GOOD、NORMAL、BAD；独行线有两个普通收束；四条 GOOD 后开放 TRUE 线。
3. 选择记录影响局部反应和最终结局，但不显示好感数值。保存、读取、返回标题、结局图鉴全部跑通。
4. 每条恋爱线至少安排一张剧情 CG，辅以原作立绘的表情差分、轻微入场/说话动作、背景变化；新增图片需要进入项目并在游戏中实际显示。
5. 检查各路线可达性、图片引用、台词切分、移动端排版、浏览器运行，以及没有剧透的选项文案。

## 视觉方向

- 氛围从第一部的雨季蓝灰过渡到秋冬海风的暖金、灰蓝。角色面容、发色、发饰和服装轮廓继承第一部参考图。
- 恋爱画面更亲密、更漂亮：露肩针织衫、方领连衣裙、合身运动服或夏末海边轻装等成年人日常穿搭；避免裸体、透视衣物、露内衣和情色姿势。主要角色设定均已年满十八岁；校园场景仍着得体校服。
- CG 优先表现互相注视、牵手、递杯子、整理衣领、靠肩等有剧情依据的接触。人物姿态服务于对话，不把角色变成与情节无关的展示。
- 表情切换：美咲迟疑/释然，玲奈倔强/浅笑，阳葵逞强/认真，乃爱冷静/温柔；动作只用短幅位移、呼吸和镜头淡入，不能妨碍阅读。

## 工作交接

- 原始剧本：`在海风消失之前_正统续作完整Galgame剧本_UTF-8.txt`，保持不改。
- 出图提示词与素材清单：`美术提示词.md`。新增素材置于 `assets/`，引用由资源表集中管理。
- 项目入口：`index.html`；数据生成脚本与人工调整在 `tools/`。生成数据可重建，别直接手改。
- 完成后在本文档补充已实现范围、测试命令和未完成事项。

## 运行与再生成

- 直接打开 `index.html` 即可游玩；也可在本目录运行 `python -m http.server 8000` 后访问本机地址。
- 修改原稿或编译规则后执行 `node tools/build.js`，再执行 `node tools/verify.js`。不要手改 `js/data.js`。
- 图片文件在 `assets/cg/`；集中资源映射在 `js/resources.js`。当前没有新配乐，游戏可静音运行。
